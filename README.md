# manual_homestuck
All [S] pages (plus a few extras) are included as locations.
All characters are included as items.
Pages cannot be cleared unless you have all of the characters required to view them in their entirety.
Use [homestuck.com/viewmap](https://homestuck.com/viewmap) to move between pages.
The distinction between what counts as a separate character is blurry in Homestuck, so if you find any inconsistency please let me know!
